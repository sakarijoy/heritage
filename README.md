# 山河足迹

中国世界遗产旅行手账，适配手机，支持离线查询、打卡、照片、评论和游记。

## iPhone 使用

用 Safari 打开 GitHub Pages 网站，选择“分享 → 添加到主屏幕”。
首次联网进入后，等待“离线资源已就绪”。无需安装描述文件。

## 个人记录

照片、游记、评论和打卡保存在当前设备的网站存储中，不上传 GitHub，也不与其他访客共享。
在景点图片下点击“上传替换”可设置本机展示图，支持每张8MB以内的照片、刷新后保留和恢复默认图；自定义展示图随完整备份导出。
请定期导出完整备份；清除浏览数据、删除网页 App 或更换网址可能需要重新导入备份。

## 地区筛选

遗产查询只按地区和省份联动筛选。
在“省份到访记录”中展开省份，可以分别勾选城市、自治州等下级地区；直辖市的下级为区县。
下级到访记录保存在本机，随完整备份迁移，不会改变遗产打卡。区划来源及年份详见 divisions.js。

## 发布设置

在仓库 Settings → Pages 中选择 Deploy from a branch，选择 main 分支和 /(root)，保存。
所有文件使用相对路径，可从 GitHub Pages 项目子目录运行。

## 数据及图片来源

遗产资料和景点代表图来自 UNESCO 世界遗产中心；图片作者及来源保留在 photos.json 中，
并在应用图片详情中显示。图片版权归各自权利人所有。
