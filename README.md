# 山河足迹

中国世界遗产旅行手账，适配手机，支持离线查询、打卡、照片、评论和游记。

## iPhone 使用

用 Safari 打开 GitHub Pages 网站，选择“分享 → 添加到主屏幕”。
首次联网进入后，先准备基础离线资源，再分批保存景点介绍图片。显示“查询与记录已可离线”时即可离线查询和记录，图片可以继续补齐。注册和安装都有超时/失败提示，可重试，不会无限等待。
“更多 → 重新准备离线资源”只重新下载应用文件，不清除IndexedDB/localStorage中的个人记录。图片缓存跨程序更新复用。无需安装描述文件。
打开、切回应用或恢复网络时自动检查新版，下载完成且无未保存输入或进行中操作时自动切换，并恢复页面与筛选位置；正在编辑、上传、备份恢复或查看弹窗时延后，结束后自动继续。保留原桌面图标，无需反复添加。

## 个人记录

照片、游记、评论和打卡保存在当前设备的网站存储中，不上传 GitHub，也不与其他访客共享。
在景点图片下点击“上传替换”可设置本机展示图，支持每张8MB以内的照片、刷新后保留和恢复默认图；自定义展示图随完整备份导出。
请定期导出完整备份；清除浏览数据、删除网页 App 或更换网址可能需要重新导入备份。

## 底部导航和省市记录

默认首页为“遗产探索”，底部左侧“遗产探索”、右侧“省市足迹”，各自保留筛选条件和内容区滚动位置。标题栏44px、底部导航49px（另加系统安全区），仅中间内容滚动。备份、恢复及使用说明集中在右上角“更多”。
省市页默认仅显示省名和到访勾选。点击省名展开详情，同一时间只展开一个省份；下级、日期备注及照片入口都在展开区域中。展开与到访勾选独立。支持全部、已到访、未到访筛选；省份和下级分别勾选计数。点击名称可填写可选日期和500字以内的备注，不改变勾选状态。支持添加和移除多次到访日期（同一天不重复），原有单日期自动保留。多日期与备注随完整备份迁移，导入旧备份会合并日期，兼容旧备份。记录弹窗限制为手机屏幕内宽度，仅允许纵向滚动。
省份和城市各有独立相册，列表显示照片数量并可直接进入；详情分为“日期与备注”和“照片”页签。每次可选1至6张、每张8MB内的照片，预览后自动压缩保存；支持逐张说明、大图查看、确认删除以及完整备份恢复。取消到访勾选不会删除相册。

遗产查询只按地区和省份联动筛选；从省市页的“查看当地遗产”进入时，可显示对应城市范围，且支持清除。
在“省份到访记录”中展开省份，可以分别勾选城市、自治州等下级地区；直辖市的下级为区县。
下级到访记录保存在本机，随完整备份迁移，不会改变遗产打卡。区划来源及年份详见 divisions.js。

## 发布设置

在仓库 Settings → Pages 中选择 Deploy from a branch，选择 main 分支和 /(root)，保存。
所有文件使用相对路径，可从 GitHub Pages 项目子目录运行。
